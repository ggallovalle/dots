# Neovim Config

A minimal Neovim configuration using `lazy.nvim` for plugin management.

## Keymaps

See [keymaps.lua](./lua/kbinit/keymap/init.lua)

## Requirements

See [health.lua](./lua/kbinit/health.lua)

## Quick Start

```bash
# Restart Neovim - plugins install automatically
nvim
```

## Usefull commands

```bash
# update plugins
:Lazy update
# inspect treesitter tree
:InspectTree
```
