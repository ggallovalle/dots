# Neovim Config

A minimal Neovim configuration using `lazy.nvim` for plugin management.

## Keymaps

See [keymaps.lua](./lua/kbinit/keymaps.lua)

## Requirements

See [doctor.lua](./lua/kbinit/doctor.lua)

## Quick Start

```bash
# Restart Neovim - plugins install automatically
nvim
```

## Updating Plugins

```bash
nvim
:Lazy update
```
